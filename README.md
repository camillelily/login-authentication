Sistema de Login Simples

Este é um projeto de login completo com:

* Front-end em HTML, CSS e JavaScript
* Back-end em Node.js
* Banco de dados MySQL

Funcionalidades:

Tela de login
Validação de campos
Comunicação com servidor
Verificação de usuário e senha no banco de dados
Mensagem de sucesso ao entrar com imagem

Tecnologias utilizadas:

* HTML5
* CSS3
* JavaScript
* Node.js
* Express
* MySQL

Estrutura do projeto

/projeto
│── index.html
│── style.css
│── script.js
│── server.js

Como funciona

1. Usuário digita login e senha
2. O JavaScript envia os dados para o servidor
3. O servidor consulta o banco de dados
4. Se estiver correto → mostra mensagem de sucesso

 Observações importantes:

* As senhas estão sem criptografia.
* Projeto feito para fins educacionais

Melhorias futuras

* Criptografia de senha (bcrypt)
* Sistema de cadastro
* Layout mais moderno
