Sistema de Login Simples

Este é um projeto de login completo com:

* Front-end em HTML, CSS e JavaScript
* Back-end em Node.js
* Banco de dados MySQL

Funcionalidades:

Tela de login
Validação de campos
Comunicação com servidor
Verificação de usuário e senha no banco de dados
Mensagem de sucesso ao entrar com imagem

Tecnologias utilizadas:

* HTML5
* CSS3
* JavaScript
* Node.js
* Express
* MySQL

Estrutura do projeto

/projeto
│── index.html
│── style.css
│── script.js
│── server.js
